# Threat model

Scope: web app, HTTP API, MCP server, worker, PostgreSQL, object storage, AI providers. Method: STRIDE per trust boundary plus agent-specific threats. Status: ✅ mitigated & tested · 🟡 mitigated, partially tested · ⏳ planned.

## Assets and data classes

| Class               | Examples                                                                    | Handling                                           |
| ------------------- | --------------------------------------------------------------------------- | -------------------------------------------------- |
| PUBLIC_DATA         | published offerings, claims, public evidence, ontology                      | broadly searchable; supplier text marked untrusted |
| TENANT_PRIVATE_DATA | buyer requirements, confidential terms, drafts, workspace data, engagements | `TenantScope`-guarded repositories, audited reads  |
| SYSTEM_DATA         | audit log, jobs, search index                                               | admin-only / internal; audit append-only           |
| SECRET_DATA         | signing keys, confirmation/asset secrets, API keys, password hashes         | env/secret store only; never logged or returned    |

## Threats and mitigations

| Threat                                                                                    | Mitigation                                                                                                                                                                                                                                                                                                                                                                                              | Status / test                                                                                               |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Prompt injection (direct)** via requirement text                                        | Text is data for interpretation only; LLM inputs delimited with explicit rules; outputs schema-validated and constrained to ontology ids; AI cannot trigger actions                                                                                                                                                                                                                                     | 🟡 `packages/ai` design; matching ignores instructions                                                      |
| **Indirect prompt injection** in supplier profiles/documents/transcripts                  | All supplier fields `untrusted: true` in API/MCP; tool results carry a notice; Skill instructs agents to treat as data; `detectInjectionSignals` flags content (`contentWarnings`, admin moderation queue); ranking uses structured claims, not prose                                                                                                                                                   | ✅ `api.int.test.ts` (flagged + ranking unchanged), MCP untrusted marking test                              |
| **Tool poisoning** (malicious tool descriptions)                                          | Tool names/descriptions are static code, not data; no dynamic tool registration from supplier input                                                                                                                                                                                                                                                                                                     | ✅ by design                                                                                                |
| **Confused deputy** (agent acting beyond user intent)                                     | Scoped agent tokens; per-tool scope challenges; consequential actions need prepare → user-approved confirm with bound token + `user_confirmed`; actions disabled by default                                                                                                                                                                                                                             | ✅ MCP consequential-action test                                                                            |
| **Cross-tenant access / BOLA / IDOR**                                                     | `authorizeTenant` → branded `TenantScope`; scoped SQL; uniform 404 for foreign ids; admins excluded from buyer data                                                                                                                                                                                                                                                                                     | ✅ API isolation tests, MCP cross-org test, Playwright                                                      |
| **Unauthorized requirement disclosure**                                                   | Supplier-facing views built by allow-list; confidential-term leak checks on every outgoing message/summary; redaction before AI/embedding calls; requirement matching uses constraint labels only                                                                                                                                                                                                       | ✅ domain tests, MCP example 4, API audit test                                                              |
| **SSRF**                                                                                  | No server-side fetching of user URLs; URL policy rejects non-https, credentials, private/internal/metadata hosts and numeric hosts                                                                                                                                                                                                                                                                      | ✅ domain URL tests, API evidence test                                                                      |
| **Malicious uploads / malware**                                                           | Allow-listed media types & sizes, magic-byte verification, EICAR detection, optional ClamAV, quarantine state, downloads as attachments with `nosniff`, signed expiring URLs                                                                                                                                                                                                                            | ✅ API upload tests                                                                                         |
| **XSS**                                                                                   | React escaping; MCP App views build DOM via `textContent` only; nonce-based CSP (no unsafe-inline/eval in production); no inline style attributes                                                                                                                                                                                                                                                       | ✅ Playwright runs against production CSP                                                                   |
| **CSRF**                                                                                  | API is bearer-only (no cookies); web mutations via Server Actions (Origin/Host check); SameSite=Lax cookie                                                                                                                                                                                                                                                                                              | 🟡 framework-provided                                                                                       |
| **OAuth mistakes / token passthrough**                                                    | Audience-bound JWTs per resource (RFC 8707); algorithm allow-list; `typ` check; RFC 9728 metadata; 401/403 challenges; MCP never forwards tokens                                                                                                                                                                                                                                                        | ✅ MCP auth tests (bad token, wrong audience, scope)                                                        |
| **Token / secret leakage**                                                                | Tokens only in httpOnly cookie or Authorization header; logger redaction of auth headers, cookies, tokens, passwords, secrets; problem responses never include internals; production refuses dev secrets                                                                                                                                                                                                | 🟡 login response test; config guard                                                                        |
| **Credential stuffing / brute force**                                                     | scrypt hashing, uniform errors, constant-work verify, per-IP auth rate limits with trusted-proxy client IP                                                                                                                                                                                                                                                                                              | 🟡                                                                                                          |
| **Excessive permissions**                                                                 | Least-privilege scopes, role ladder per organization, agent tokens ≤ 90 days, individually revocable and ≤ the user's scopes                                                                                                                                                                                                                                                                            | ✅                                                                                                          |
| **Accidental external action**                                                            | Feature flag, explicit preview of shared/not-shared fields, idempotency keys                                                                                                                                                                                                                                                                                                                            | ✅                                                                                                          |
| **Data exfiltration through agent workflows**                                             | Compact results; private data only to authenticated members with scopes; audit of requirement reads/matches                                                                                                                                                                                                                                                                                             | 🟡                                                                                                          |
| **AI hallucinated capabilities/certifications**                                           | Closed predicate set; `CERTIFIED` requires certification body; grounding check (verbatim quote); weakest-cue predicate; drafts need human publication; never auto-verified                                                                                                                                                                                                                              | ✅ domain + API tests                                                                                       |
| **Malicious supplier metadata** (rank manipulation)                                       | Scores built from structured claims with trust weights; text relevance capped at 20 %; admin moderation and verification                                                                                                                                                                                                                                                                                | 🟡                                                                                                          |
| **Denial of service**                                                                     | Body limits, rate limits, bounded constraints/limits/pagination, statement timeouts                                                                                                                                                                                                                                                                                                                     | 🟡                                                                                                          |
| **Impersonation / fake suppliers**                                                        | Invite-only registration (ADR-0012); content public only for platform-verified organizations; suspension unlists immediately (ADR-0011)                                                                                                                                                                                                                                                                 | ✅ API + MCP listing tests, Playwright onboarding                                                           |
| **Invitation token theft / reuse**                                                        | 256-bit tokens, hash-only storage, email-bound, single-use, 14-day expiry, POST lookup (no tokens in API URLs), uniform errors, rate limits, strict referrer policy                                                                                                                                                                                                                                     | ✅ API registration tests                                                                                   |
| **Account takeover / lost credentials**                                                   | Password reset by single-use 1 h link (hash stored), no account enumeration, 3/h per account; reset and sign-out-everywhere revoke all sessions, agent tokens and OAuth grants incl. refresh tokens (`credentials_changed_at`, ms precision); operators can do the same for a compromised account (`pnpm admin:revoke-access`)                                                                          | ✅ `account.int.test.ts`, `oauth.int.test.ts` (revocation), Playwright recovery journey                     |
| **Unverified identities acting externally**                                               | Verified email required to create organizations and to confirm engagement requests                                                                                                                                                                                                                                                                                                                      | ✅ account integration test                                                                                 |
| **Phishing via platform emails** (links in user-controlled names)                         | Plain-text emails only; URL-like text stripped from display and organization names in every outgoing email                                                                                                                                                                                                                                                                                              | ✅ unit test `plainName`                                                                                    |
| **Leaked agent token**                                                                    | Per-token grants: list with last use, immediate individual revocation (401 `invalid_token`), scope ceiling, max 90 days; tokens mintable only from first-party sessions (no agent self-minting)                                                                                                                                                                                                         | ✅ `apps/mcp-server/test/agent-tokens.int.test.ts`, `test/integration/agent-tokens.int.test.ts`, Playwright |
| **OAuth abuse** (code interception, redirect manipulation, token theft, consent phishing) | Public clients + mandatory PKCE S256; exact redirect matching (loopback port exception); dangerous schemes rejected; resource indicator bound to the MCP server; `iss` response parameter; single-use codes (replay revokes grant); rotating refresh tokens with reuse detection; consent only in first-party sessions, client names labelled unverified, redirect origin shown; no CIMD fetches (SSRF) | ✅ `test/integration/oauth.int.test.ts` (official SDK), domain tests, Playwright consent                    |
| **Insecure production configuration**                                                     | Startup guard refuses development secrets, development mailers, missing ClamAV and an implicit database TLS mode; demo-account hints only with `SHOW_DEMO_ACCOUNTS`; HSTS on web and API over https; dependency audit clean                                                                                                                                                                             | ✅ `packages/config/test/config.test.ts`; `pnpm audit`                                                      |
| **Audit tampering**                                                                       | Append-only trigger on `audit_events`                                                                                                                                                                                                                                                                                                                                                                   | ✅ schema                                                                                                   |

## Residual risks / next steps

- ⏳ External IdP subject mapping (ADR-0004); the built-in OAuth AS for MCP hosts is in place (ADR-0017).
- ⏳ PostgreSQL row-level security as defence in depth for tenant tables.
- ⏳ Distributed rate limiting (Redis or gateway) for multi-instance deployments.
- ⏳ KMS-backed signing keys and overlapping-key rotation (today: single key; rotation signs everyone out — see `docs/operations/runbook.md`).
- ⏳ Content Disarm & Reconstruction for PDFs. (Production AV scanning is now mandatory: the configuration refuses to start without `CLAMAV_HOST`.)
- ⏳ Least-privileged database roles (app role without DDL; migrations role separate).
